First public release. Use a Wii Remote + Guitar Hero guitar as a controller in
Clone Hero and YARG on Android, with no PC, DolphinBar or root.

**Needs [Shizuku](https://shizuku.rikka.app/)** (free) running. See the
README for setup.

- Pairing helper that answers the Wii Remote's binary PIN (SYNC pairing
  recommended; the Wii Remote then reconnects with any button).
- Each guitar becomes a standard "Wiitar Guitar N" controller: frets, strum,
  plus/minus, tilt for star power, touch strip.
- Press-to-assign remapping, touch strip modes (axis / frets / whammy),
  per-guitar profiles, tilt calibration.
- Multiple guitars, battery level, rumble to identify players, auto-start
  when a Wii Remote connects.
- AYN Odin: option to stop the built-in mapping app taking over Wii guitars,
  for real whammy.

Tested on an AYN Odin 3 Max (Android 15). Known limits: player lights depend
on the device, and drums aren't supported yet.

Install `wiitar-0.1.0.apk` from the assets below.
